# Institutional Branding Assets Directory

This directory is designated for official institutional branding assets for **Agent 63 – Data Analytics Agent**.

## Strict Rules on Branding Assets
1. **DO NOT generate fake institutional logos or AI placeholders.**
2. **DO NOT download or use arbitrary internet logos.**
3. **DO NOT recreate institutional crests or logos using CSS.**
4. Only use official, high-resolution vector (SVG) or transparent PNG assets supplied by the college administration/project lead.

## Expected Asset Placements & File Naming Conventions
When official institutional assets are provided, place them in this folder using the following standardized names:

| Asset Name / Path | Expected Role & Description | Format |
| :--- | :--- | :--- |
| `institution-logo.png` / `.svg` | Official College / Institution Crest and Wordmark (Header top-left) | SVG or High-res PNG |
| `department-logo.png` / `.svg` | Department / CSE Emblem or Event Sub-branding (Header center/identity) | SVG or High-res PNG |
| `accreditation-logo-01.png` / `.svg` | Primary Accreditation / Recognition (e.g., NAAC / NBA / Autonomous badge, Header top-right) | SVG or High-res PNG |
| `accreditation-logo-02.png` / `.svg` | Secondary Accreditation / Affiliation (e.g., University affiliation, Header top-right) | SVG or High-res PNG |
| `agent-63-mark.svg` | Agent 63 Project Identifier / Badge | SVG or High-res PNG |
